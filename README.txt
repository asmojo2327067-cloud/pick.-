pick. v0.2 AUTO

PDFから部材候補を自動拾いする試作版です。

使い方
1. PDFを選択
2. 自動OCRが全ページを解析
3. 部材名と近くの寸法から候補を作成
4. 候補を確認・修正
5. 採用分を書き出す

プライバシー
- PDF本体・図面画像をアップロードする処理はありません。
- PDF.js / Tesseract.js / OCR辞書は初回にインターネットから読み込みます。
- OCR処理はブラウザ内で実行されます。

注意
- 寸法線・注記が密集した施工図では誤推定があります。
- 自動候補は必ず原図で確認してください。
- 現段階は「完全自動確定」ではなく「自動候補→人が確認」を目的にしています。
